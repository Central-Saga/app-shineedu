## 📖 Cara Menggunakan Dokumentasi

### **Pertama Kali?**

1. Buka folder modul yang ingin Anda pelajari
2. Baca file `README.md` di folder tersebut
3. Ikuti recommended reading order

### **Cari Fitur Spesifik?**

1. Lihat struktur folder di atas
2. Buka folder yang relevan
3. Baca dokumentasi spesifik

### **Troubleshooting?**

2. Cari section "Troubleshooting"
3. Ikuti solusi yang diberikan
